# CallVault

Android app (Kotlin + Jetpack Compose). The APK is built automatically by GitHub Actions.

## Download the APK
1. Open the **Actions** tab → **Build CallVault APK** → latest green run.
2. Scroll to **Artifacts** → download `CallVault-debug-apk` (a .zip) → unzip → `app-debug.apk`.
3. Copy it to an Android phone and install (allow "Install unknown apps").
